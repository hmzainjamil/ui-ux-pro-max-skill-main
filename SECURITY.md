# Security and design-data guidance

Design files and prompts may include unreleased product plans, customer information, credentials, or proprietary visual assets. Use approved AI providers and tools for the data involved. Inspect any command, plugin, or skill source before enabling it, and test with non-sensitive examples first.

Design recommendations require human review for accessibility, platform guidance, licensing, and product context. This repository has not been validated as a working skill or security-audited in this review.

Report vulnerabilities privately through GitHub reporting if enabled, or contact the maintainer through a private channel. Do not post secrets publicly.
